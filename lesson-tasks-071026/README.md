## Задача №1. Оптимальное производство часов

### Условие

Некоторое предприятие выпускает две марки литых часов (n = 2) с условными названиями «Ваниль» и «Президент». Для изготовления часов «Ваниль» требуется 50 г золота и 30 г платины, а для «Президент» — 40 г золота и 50 г платины (m = 2). Предприятие продаёт часы «Ваниль» по цене 1500 за 1 шт., а «Президент» — по 2100 за 1 шт. Запасы драгоценных металлов на складе предприятия ограничены: золота — 1.5 кг, платины — 1.8 кг.

Требуется определить оптимальную партию часов «Ваниль» и «Президент», которую может изготовить предприятие с целью получения максимальной прибыли.

### Математическая модель

Пусть x1 — число часов «Ваниль», x2 — «Президент».

    max Z = 1500*x1 + 2100*x2

    при ограничениях:
        50*x1 + 40*x2 <= 1500
        30*x1 + 50*x2 <= 1800
        x1, x2 >= 0, целые

## Задача №2. Оптимальное число скорых и пассажирских поездов

### Условие

Между двумя городами установлено железнодорожное сообщение, при этом перевозка пассажиров осуществляется пассажирскими и скорыми поездами. Каждый из видов поездов имеет в своём составе предельное число вагонов различного типа: багажный, почтовый, плацкартный, купейный, мягкий. Известно количество пассажиров, перевозимых в каждом из типов вагонов, а также общее число вагонов каждого типа на станции формирования поездов (таблица).

| Тип вагона | Скорый | Пассажирский | Всего вагонов |
|---|---|---|---|
| Багажный | 1 | 1 | 5 |
| Почтовый | 1 | — | 6 |
| Плацкартный | 8 | 4 | 43 |
| Купейный | 4 | 1 | 32 |

Требуется определить оптимальное число скорых и пассажирских поездов, при которых общее число перевозимых пассажиров будет максимальным.

### Математическая модель

Пусть x — число скорых поездов, y — пассажирских; n1, n2 — пассажировместимость скорого и пассажирского поезда.

    max N = n1*x + n2*y

    при ограничениях:
        x + y <= 5
        x <= 6
        8*x + 4*y <= 43
        4*x + y <= 32
        x, y >= 0, целые

## Задача №3. Маневры летательного аппарата

По техническим условиям ЛА одновременно может либо набирать высоту, либо увеличивать скорость. Имеется 3 последовательных режима набора высоты и 3 последовательных режима увеличения скорости. Известен расход топлива и время, необходимые для выполнения манёвров в различных режимах. Схема манёвров представлена ориентированным графом (рис. 10.21). Вершина 1 — начальное состояние, вершина 16 — конечное.

Требуется определить последовательность режимов набора высоты и скорости так, чтобы достичь заданной высоты и скорости, обеспечив минимальный расход топлива и минимальное время выполнения всего манёвра.

Парето-оптимальные пути из вершины 1 в вершину 16 в двухкритериальном графе (топливо, время).

## Задача №4. Оптимальная флотилия судов

### Условие

Туристская фирма располагает флотилией из трёх типов судов, характеристики которых представлены в таблице.

| Показатели | Буревестник | Альбатрос | Чайка |
|---|---|---|---|
| Пассажировместимость, чел. | 3000 | 2000 | 1000 |
| Расход горючего, т/мес. | 20000 | 12000 | 7000 |
| Экипаж, чел. | 350 | 250 | 100 |
| Затраты на содержание и обслуживание, млн руб./мес. | 10 | 8 | 5 |

В месяц выделяется 70 000 т горючего. Наличие рабочей силы не превышает 1100 чел.

Требуется определить количество судов каждого типа, отправляющихся в круиз, чтобы при минимальных затратах обеспечить путевками 10 тыс. желающих.

### Математическая модель

Пусть x1, x2, x3 — число судов «Буревестник», «Альбатрос», «Чайка».

    min Z = 10*x1 + 8*x2 + 5*x3

    при ограничениях:
        3000*x1 + 2000*x2 + 1000*x3 >= 10000
        20000*x1 + 12000*x2 + 7000*x3 <= 70000
        350*x1 + 250*x2 + 100*x3 <= 1100
        x1, x2, x3 >= 0, целые

## Задача №5. Оптимальные упаковки сухофруктов

### Условие

Коммерческие расчёты, проведённые студентами в деревне, привели к более выгодному использованию плодов яблок и груш путём их засушки и последующей продажи зимой в виде смеси сухофруктов. Подсчитано, что из 1 кг плодов получается 200 г сушёных яблок, а груш — 250 г.

| Плоды | Смесь 1 | Смесь 2 | Сбор, кг/день |
|---|---|---|---|
| Анис (яблоки) | 0.25 | 0.25 | 14 |
| Штрейфлинг (яблоки) | 0.75 | 0.25 | 22.5 |
| Груши | 0 | 0.5 | 12 |
| Оптовая цена упаковки, руб./шт. | 40 | 50 | |

Требуется определить оптимальное количество упаковок сухофруктов по 1 кг смесей первого и второго вида, обеспечивающих максимальный доход от продажи.

### Математическая модель

Пусть y1, y2 — число упаковок смеси 1 и смеси 2.

    max Z = 40*y1 + 50*y2

    при ограничениях:
        0.25*y1 + 0.25*y2 <= 14 * 0.2  = 2.8
        0.75*y1 + 0.25*y2 <= 22.5 * 0.2 = 4.5
        0.5*y2             <= 12 * 0.25 = 3.0
        y1, y2 >= 0

## Задача №6. Максимальный путь в графе (БЛП)

### Условие

Дан ориентированный граф с вершинами A, B, C, D, E, F и дугами:

| Дуга | Вес |
|---|---|
| A -> B | 4 |
| A -> C | 2 |
| B -> C | 5 |
| B -> D | 10 |
| C -> E | 3 |
| E -> D | 4 |
| D -> F | 11 |

Требуется построить математическую модель задачи булева линейного программирования (БЛП) для нахождения максимального пути из A в F.

### Математическая модель

Введём булевы переменные x_ij, принимающие значения 0 или 1, для каждой дуги (i, j).

Целевая функция:

    max SUM_{(i,j) in E} w_ij * x_ij

Ограничения баланса потоков:

    для i = A (источник):   SUM_{j} x_Aj - SUM_{j} x_jA = 1
    для i = F (сток):       SUM_{j} x_Fj - SUM_{j} x_jF = -1
    для i in {B,C,D,E}:     SUM_{j} x_ij - SUM_{j} x_ji = 0

Условие булевости переменных:

    x_ij in {0, 1}   для всех (i, j) в E

### Пояснение

- Из источника A выходит ровно одна выбранная дуга — путь начинается.
- В сток F входит ровно одна выбранная дуга — путь заканчивается.
- Для всех промежуточных вершин выполняется закон сохранения потока: сколько вошло, столько и вышло.
- Такая модель автоматически исключает «вилки» и «слияния», оставляя единственный простой путь из A в F.

### Известное решение

Путь A -> B -> C -> E -> D -> F с суммарным весом 4 + 5 + 3 + 4 + 11 = 27.

from pulp import LpProblem, LpVariable, LpMaximize, LpStatus, value

prob = LpProblem("Chasy", LpMaximize)
x1 = LpVariable("Vanil", lowBound=0, cat='Integer')
x2 = LpVariable("Prezident", lowBound=0, cat='Integer')

prob += 1500*x1 + 2100*x2, "Vyruchka"
prob += 50*x1 + 40*x2 <= 1500, "Zoloto"
prob += 30*x1 + 50*x2 <= 1800, "Platina"

prob.solve()
print("Статус:", LpStatus[prob.status])
print(f"Ваниль = {int(value(x1))}, Президент = {int(value(x2))}")
print(f"Максимальная выручка = {value(prob.objective)}")
