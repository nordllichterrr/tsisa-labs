# Практическая работа №7. Метод анализа иерархий (Вариант 15)

## Тема ВКР
Разработка СППР для управления учебным процессом в вузе при подборе учебной литературы на основе VARK и LLM.

## Цель работы
Получить навыки решения задач многокритериального выбора альтернатив с применением метода анализа иерархий (МАИ) и автоматизировать расчёты на Python.

## Постановка задачи
Необходимо выбрать оптимальную учебную книгу из трёх альтернатив для студента 2 курса по дисциплине «Python для анализа данных» (IT-дисциплина, цель — подготовка к экзамену, VARK-профиль — визуал).

**Альтернативы:**
- A1: Учебник «Python для анализа данных» (2023)
- A2: Практикум «Python: задачи и решения» (2021)
- A3: Монография «Data Science: теория» (2019)

**Критерии (из ЛР №2 и ЛР №3):**

| Обозн. | Критерий | Вес из БЗ |
| :--- | :--- | :--- |
| K1 | Соответствие стилю VARK | 0.35 |
| K2 | Соответствие цели изучения | 0.25 |
| K3 | Новизна издания | 0.15 |
| K4 | Соответствие ФГОС | 0.15 |
| K5 | Трудозатраты на чтение | 0.10 |

## Шаги МАИ

### 1. Иерархия
Цель → Критерии (K1–K5) → Альтернативы (A1–A3).

### 2. Матрица парных сравнений критериев
Получены веса критериев и проверена согласованность (CR). Результаты в main.py при запуске.

### 3. Матрицы парных сравнений альтернатив
Для каждого критерия построена матрица 3×3 и вычислены локальные приоритеты.

### 4. Синтез глобальных приоритетов
F(A_j) = Σ w_i · x_ij.

### 5. Выбор лучшей альтернативы
По результатам расчёта выводится наилучшая книга.
