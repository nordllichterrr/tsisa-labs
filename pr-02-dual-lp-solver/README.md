# Dual LP Solver

Решение прямой и двойственной задач линейного программирования
(практическая работа №2 по дисциплине «Теория систем и системный анализ»).

## Постановка задачи

**Прямая задача (max):**

    3x1 + 4x2 + 2x3 -> max

при ограничениях:

    x1 + 4x2 + 2x3 <= 25
    2x1 + x2 + 3x3 <= 31
    x1 + 5x2 + x3 <= 37
    5x1 + x2 + 2x3 <= 39
    x1, x2, x3 >= 0

**Двойственная задача (min):**

    25y1 + 31y2 + 37y3 + 39y4 -> min

при ограничениях:

    y1 + 2y2 + y3 + 5y4 >= 3
    4y1 + y2 + 5y3 + y4 >= 4
    2y1 + 3y2 + y3 + 2y4 >= 2
    y1, y2, y3, y4 >= 0

## Запуск

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python dual_lp_solver.py

## Анализ дефицитности ресурсов

Согласно теоретическим положениям, изложенным в п. 2.3 методички, если некоторый тип сырья используется полностью, то соответствующая этому типу двойственная переменная в оптимальном решении двойственной задачи будет иметь положительное значение. Если же сырьё используется не полностью, двойственная переменная равна нулю.

Применительно к рассматриваемой задаче анализ дефицитности ресурсов даёт следующие результаты:

- **Ресурс №1 используется полностью** — соответствующая двойственная переменная положительна: `y1 = 0.894737`. Это означает, что увеличение запаса данного типа сырья на 1 кг приведёт к приросту максимального значения целевой функции прямой задачи на 0.894737.

- **Ресурс №2 используется не полностью** — двойственная переменная равна нулю: `y2 = 0`. Дополнительное количество этого сырья не изменит оптимального значения целевой функции.

- **Ресурс №3 используется не полностью** — двойственная переменная равна нулю: `y3 = 0`. Дополнительное количество этого сырья не изменит оптимального значения целевой функции.

- **Ресурс №4 используется полностью** — соответствующая двойственная переменная положительна: `y4 = 0.421053`. Увеличение запаса данного типа сырья на 1 кг приведёт к приросту максимального значения целевой функции прямой задачи на 0.421053.

Таким образом, **дефицитными типами сырья являются ресурсы №1 и №4**, а ресурсы №2 и №3 — **недефицитные**. Двойственные оценки показывают степень дефицитности каждого типа сырья: чем больше значение двойственной переменной, тем «ценнее» дополнительная единица этого ресурса.

Полученные результаты согласуются с теоремой двойственности: оптимальные значения целевых функций прямой и двойственной задач совпадают и равны **38.789474**.
