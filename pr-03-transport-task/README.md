# Лабораторная работа №3. Транспортная задача (вариант 15)

Решение классической закрытой транспортной задачи линейного
программирования с использованием `scipy.optimize.linprog` (метод HiGHS).

## Постановка задачи

Сельскохозяйственные кооперативы выращивают картофель. В качестве пунктов
потребления выступают склады. Требуется определить оптимальный план
перевозок картофеля так, чтобы весь выращенный картофель был отправлен
на склады, а суммарные затраты на транспортировку были минимальными.

**Исходные данные** (стоимость перевозки 1 тонны, тыс. руб.):

| Кооператив \\ Склад | Склад №1 | Склад №2 | Склад №3 | Производство, т |
|---|---:|---:|---:|---:|
| Кооператив №1 | 77 | 80 | 48 | 95 |
| Кооператив №2 | 65 | 42 | 79 | 150 |
| Кооператив №3 | 85 | 51 | 52 | 125 |
| Кооператив №4 | 60 | 78 | 76 | 140 |
| **Потребности, т** | **155** | **180** | **175** | |

**Проверка сбалансированности:** 95 + 150 + 125 + 140 = 510;
155 + 180 + 175 = 510. Задача закрытая.

## Математическая постановка

Целевая функция:

    77·x11 + 80·x12 + 48·x13 +
    65·x21 + 42·x22 + 79·x23 +
    85·x31 + 51·x32 + 52·x33 +
    60·x41 + 78·x42 + 76·x43 -> min

Ограничения:

    x11 + x12 + x13 = 95
    x21 + x22 + x23 = 150
    x31 + x32 + x33 = 125
    x41 + x42 + x43 = 140

    x11 + x21 + x31 + x41 = 155
    x12 + x22 + x32 + x42 = 180
    x13 + x23 + x33 + x43 = 175

    xij >= 0, i in {1..4}, j in {1..3}

## Результат

**Оптимальный план перевозок (тонн):**

| Кооператив \\ Склад | Склад №1 | Склад №2 | Склад №3 | Производство |
|---|---:|---:|---:|---:|
| Кооператив №1 | 0 | 0 | 95 | 95 |
| Кооператив №2 | 15 | 135 | 0 | 150 |
| Кооператив №3 | 0 | 45 | 80 | 125 |
| Кооператив №4 | 140 | 0 | 0 | 140 |
| **Потребности** | **155** | **180** | **175** | |

**Минимальные суммарные затраты:** **26 060 тыс. руб.**

### Проверка вручную

- К1 -> С3: 95 · 48 = 4 560
- К2 -> С1: 15 · 65 = 975
- К2 -> С2: 135 · 42 = 5 670
- К3 -> С2: 45 · 51 = 2 295
- К3 -> С3: 80 · 52 = 4 160
- К4 -> С1: 140 · 60 = 8 400

Итого: 4 560 + 975 + 5 670 + 2 295 + 4 160 + 8 400 = **26 060 тыс. руб.**

Все суммы по строкам и столбцам совпадают с производствами и
потребностями, ограничения неотрицательности выполнены.

## Метод решения

Задача сформулирована как задача линейного программирования в
стандартной форме и решена методом `highs` из `scipy.optimize.linprog`
(комбинация симплекс-метода и метода внутренней точки). Матрица
ограничений строится автоматически: `m + n` строк, `m · n` столбцов.
