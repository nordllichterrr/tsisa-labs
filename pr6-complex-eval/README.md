# PR-06 — Метод комплексной оценки (ТСиСА, раздел 4.2)

Применение метода комплексной оценки для задачи подбора учебной литературы
в СППР на основе LLM + VARK.

## Постановка

Необходимо ранжировать электронные учебники `Y1..Y4` по пяти критериям:

| Критерий | Описание | Направление | VARK |
|----------|----------|-------------|------|
| K1 | Стоимость | min | — |
| K2 | Объективность изложения | max | R |
| K3 | Поддержка средств тестирования | max | K |
| K4 | Лёгкость и простота использования | max | V |
| K5 | Соответствие VARK-профилю студента | max | — |

Веса критериев заданы двумя экспертами: преподавателем и методистом.

## Алгоритм

1. Усреднение весов экспертов -> `V_i`.
2. Разброс оценок по критерию -> `R_i = max(P_ij) - min(P_ij)`, `R = sum R_i`.
3. Веса по разбросу -> `Z_i = R_i / R`.
4. Обобщённые веса -> `W_i = (V_i + Z_i) / 2`.
5. Взвешенные оценки -> `E_ij = P_ij * W_i`.
6. Комплексная оценка объекта -> `E_j = sum_i E_ij`.

Альтернатива с максимальной `E_j` — предпочтительная.

## Запуск

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python complex_eval.py -v -o report.json

## Результат

Итоговый рейтинг: `Y3 > Y2 > Y1 > Y4`.
Рекомендуется учебник `Y3`.
