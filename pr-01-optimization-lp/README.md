# Решение задач линейного программирования

## Описание
Решение трех задач линейного программирования с использованием `scipy.optimize.linprog`.

## Задачи
1. **Оптимизация производства клея** - максимизация стоимости продукции
2. **Оптимизация производства красок** - максимизация прибыли
3. **Оптимизация посева культур** - максимизация прибыли фермера

## Результаты
- Задача 1: Максимальная стоимость = 46000 руб.
- Задача 2: Максимальная прибыль = 160 тыс.руб.
- Задача 3: Максимальная прибыль = 96000 тыс.руб.

## Технологии
- Python 3.7+
- SciPy
- NumPy

## Запуск
```bash
pip install -r requirements.txt
python3 task1.py
python3 task2.py
python3 task3.pyEOF
