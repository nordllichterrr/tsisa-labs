Отчёт по практической работе №1 по дисциплине
«Теория систем и системный анализ». Вариант №15.

**Тема:** Основы решения задач линейного программирования.

## Постановка задачи

Завод выпускает 3 вида мороженого. Для их изготовления используются
2 исходных продукта: молоко и наполнители. Известны расходы исходных
продуктов на 1 кг мороженого каждого вида, суточные запасы сырья,
отпускные цены и максимальный спрос на мороженое №2.

Требуется определить такие суточные объёмы производства мороженого
x1, x2, x3 (в кг), при которых общий доход предприятия от реализации
всей продукции будет максимальным с учётом имеющихся ограничений
по сырью и спросу.

### Исходные данные

| Показатель | Ед. изм. | Мороженое №1 | Мороженое №2 | Мороженое №3 | Суточный запас |
|---|---|---|---|---|---|
| Расход молока | кг/кг | 0.65 | 0.59 | 0.49 | 525 кг |
| Расход наполнителей | кг/кг | 0.55 | 0.70 | 0.61 | 410 кг |
| Цена реализации | ден. ед./кг | 100 | 120 | 115 | — |
| Спрос (ограничение) | кг/сутки | — | ≤ 200 | — | — |

### Математическая постановка

    Z = 100*x1 + 120*x2 + 115*x3 -> max

при ограничениях:

    0.65*x1 + 0.59*x2 + 0.49*x3 <= 525   (молоко)
    0.55*x1 + 0.70*x2 + 0.61*x3 <= 410   (наполнители)
    1*x2                        <= 200   (спрос на мороженое №2)
    x1 >= 0, x2 >= 0, x3 >= 0

## Анализ результата

- **Оптимальный план производства:** выпускать только мороженое №3
  в объёме 672.13 кг/сутки. Мороженое №1 и №2 производить невыгодно
  при заданных ценах и расходах сырья.
- **Наполнители** — дефицитный ресурс: расходуется полностью (410 из
  410 кг). Именно это ограничение определяет оптимальный объём выпуска.
- **Молоко** — недефицитный ресурс: израсходовано 329.34 кг из 525 кг,
  остаток 195.66 кг.
- **Ограничение по спросу на мороженое №2** неактивно: продукт
  не выпускается, поэтому спрос не является ограничивающим фактором.
